# Kolmeia (kolmeia.ai)

SaaS de **prospecção por e-mail frio** para o mercado brasileiro, na mesma categoria do Instantly:
conecta as caixas do cliente, faz rodízio com limite diário e aquecimento, roda sequências que param quando o lead responde,
junta as respostas numa caixa só com rótulos da IA e registra tudo num **Diário**.
Primeiro cliente de teste: NEAir HVAC (Massachusetts) prospectando construtoras.

**Status: só protótipo, nada programado.** Nenhum e-mail é enviado; dados de atividade são exemplo.
Os leads são linhas reais de `docs/prototipos/central-prospeccao.html`.

## Pastas
| Pasta | O que tem |
|---|---|
| `prototipo/kolmeia-telas.html` | protótipo clicável de todas as telas (abrir no navegador). Botão **Mapa de telas** = lista para aprovar tela por tela |
| `brand/` | `logo.svg`, `logo-mark.svg`, `identidade.md` (cores, fontes, regras) |
| `docs/` | vazio por enquanto (specs virão depois da aprovação das telas) |

## Como aprovar
1. Abrir o protótipo.
2. Clicar em **Mapa de telas** (canto de baixo).
3. Ir em cada tela, marcar **aprovada** (fica salvo no navegador).
